Geolocator

A C# console-based IP geolocation tool that uses the ipinfo.io API to retrieve approximate location and network information from an IP address.

About

This project was created as a learning exercise based on the "Make a IP address GeoLocator!" tutorial by Ebola Man.

The project helped me practice:

C# classes and properties
HTTP requests with HttpClient
JSON deserialization
async / await
API integration
Exception handling
Nullable reference types
Disclaimer

This tool provides approximate IP-based geolocation information. It does not determine a user's exact physical location.
